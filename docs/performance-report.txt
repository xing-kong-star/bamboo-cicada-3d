## 关键优化定位

先关掉 3D 场景只测 HUD，再逐项隐藏 UI 后发现：

- 左下角仪表盘的 SVG 宽高/位移过渡 + 进度条过渡 + 提示箭头 CSS 动画持续以 60fps 重绘合成，单独占用约 **17% 单核 GPU**。
- 全屏 CSS 暗角叠加层额外占用约 **6% 单核 GPU**。
- 移除这些连续 HUD 动画、把 HUD 背景改不透明、移除仪表盘阴影和 2D 波形画布，并把仪表盘/挑战卡刷新降到 10Hz/5Hz 后：
  - Edge GPU 进程从旋转时的约 **0.46 核降到 0.21 核**。
  - 整个页面不再随 HUD 以 60fps 重绘，只有 3D 画面按 30fps 更新。

## 复测项

- 默认流畅模式：30fps、720p 上限、无实时阴影、无全屏后处理。
- 高画质模式：60fps、1080p 上限、AfterimagePass。
- 页面切后台：渲染循环停止、AudioContext 暂停、MediaPipe 摄像头停止。
- 返回前台：渲染循环恢复、音频恢复。
- 打开帮助 / 结算弹窗：渲染循环暂停。
- 打开手势面板不会自动启动摄像头。
- 摄像头与 MediaPipe 均限制为 15fps，关闭面板立即停止。
- 物理使用 1/60s 固定步长，maxSubSteps = 4。
- 所有功能验收与音频验收通过，无页面脚本错误。
